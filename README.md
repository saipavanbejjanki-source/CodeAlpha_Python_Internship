# CodeAlpha Python Internship Projects

This repository contains the projects completed as part of the CodeAlpha Python Programming Internship. These projects were developed using Python and demonstrate fundamental programming concepts such as loops, conditional statements, functions, dictionaries, file handling, and user interaction.

## Projects

### 1. Hangman Game
A text-based word guessing game where the player attempts to guess a hidden word one letter at a time. The game provides a limited number of incorrect attempts before ending.

## Technologies Used
- Python 3
- Pydroid 3 (Android)

## Learning Outcomes
- Python Programming Basics
- Loops and Conditional Statements
- Functions and Data Structures
- File Handling
- User Input and Output
- Problem Solving.
